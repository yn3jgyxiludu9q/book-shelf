# book-shelf

Text samples used while working on things that parse prose.

`crime-and-punishment/` is the Project Gutenberg edition of Dostoevsky's
*Crime and Punishment* (ebook #2554, Constance Garnett translation), split by part.
It is public domain and about 1.1 MB, which makes it far more useful as an input
than a fifty-line sample typed by hand: real paragraph lengths, dialogue dashes,
chapter headings, and enough volume that a slow regex actually shows up.

Nothing here is required to build anything. It sits in the repo so benchmarks run
against a file I did not write myself.
